Generar código QR

Genera el código qr que será escaneado por el cliente

Authorizations:
bearerHttpAuthentication
Request Body schema: application/json
amount
required
number

Monto de la compra

lineas
required
Array of strings

Descripción del producto comprado

metaData
required
object

Información adicional útil para identificar al usuario que efectúa la transacción. No se limita a los ejemplos proporcionados.
